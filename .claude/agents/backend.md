# Agente: Especialista Backend (Backend Developer)

## Misión y Responsabilidades
El Agente Backend se encarga de implementar y mantener el código PHP 8.2+, la capa `BLL`, la capa `DAL`, los controladores delgados y las entidades `ADO`.

## Funciones Principales
1. Implementar la lógica de negocio en clases `*BLL` heredando de `BaseBLL`.
2. Escribir consultas SQL parametrizadas en clases `*DAL` heredando de `BaseDAL`.
3. Modelar los objetos tipados `ADO*` heredando de `BaseADO`.
4. Construir controladores orquestadores y clases `FormRequest` con validaciones robustas.
5. Asegurar el tipado estricto (`declare(strict_types=1);`) y el cumplimiento de PSR-12.
