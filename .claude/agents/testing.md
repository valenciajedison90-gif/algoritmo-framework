# Agente: Ingeniero de Pruebas (QA & Testing Engineer)

## Misión y Responsabilidades
El Agente de Pruebas diseña y ejecuta baterías de pruebas unitarias, de integración y end-to-end (E2E) con PHPUnit o Pest.

## Funciones Principales
1. Construir pruebas unitarias para cada método de la capa `BLL`, verificando casos de éxito y de fallo.
2. Comprobar que las excepciones `BusinessException` se disparen ante condiciones inválidas.
3. Crear pruebas de integración para la capa `DAL` con bases de datos en memoria (`:memory:`).
4. Ejecutar pruebas automatizadas del flujo de autenticación, logout y control de sesiones.
